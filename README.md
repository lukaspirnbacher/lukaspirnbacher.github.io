# lukaspirnbacher.github.io

Personal academic homepage of Lukas Pirnbacher, built with Jekyll and the
[Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) theme and hosted on GitHub Pages.

## Where things are

| What you want to change        | File                                  |
|--------------------------------|---------------------------------------|
| Photo                          | `assets/images/profile.jpg`           |
| CV                             | `files/cv_pirnbacher.pdf` (replace, keep the name) |
| Sidebar: title line and links  | `_config.yml` → `author:`             |
| Top menu                       | `_data/navigation.yml`                |
| Home page text                 | `_pages/home.md`                      |
| Papers                         | `_pages/research.md`                  |
| Courses                        | `_pages/teaching.md`                  |

Edit any file directly on github.com (pencil icon → "Commit changes").
The site rebuilds automatically within about a minute; progress is shown under the "Actions" tab.
